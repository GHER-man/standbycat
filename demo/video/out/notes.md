## 静夜时钟 v7.3

一个给床头/桌面用的横屏时钟：全屏常亮、纯黑底、超大液态玻璃数字，瞄一眼就知道几点。

**功能**
- 四个页面：倒计时 / 数字钟 / 计时器 / 模拟指针，上下滑动切换
- 液态玻璃数字：7 层叠加 + 位图缓存，UI 绘制耗时 0.53ms
- 倒计时：在数字上上下滑动设时长（滚轮手感），结束按闹钟节奏持续震动
- 按键液态玻璃底 + 按下回弹；夜间模式全屏转暗红
- 简化动效开关（省电模式）；日历含农历 / 节气 / 节假日 / 倒数日
- 防烧屏漂移；不联网、不收集任何数据

**本版修复**
- 位图缓存 key 未实现 `equals/hashCode` → 每帧新建位图 → 几分钟后 OOM 闪退（顺带把卡顿一起修了）

- `standbycat-promo.mp4` — 宣传片（35 秒，1920×864，H.264）
